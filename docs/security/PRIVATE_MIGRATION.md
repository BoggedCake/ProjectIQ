## Prepared code and boundaries

- `scripts/scan-secrets.py`: current non-ignored working files plus all reachable Git blobs, with rule/object identifiers only (working filenames hashed); no candidate values or matching lines. Narrow signature scanner, not a replacement for provider-native scanning.
- `scripts/build-founder-assets.cjs`: allowlisted static package, excludes API sources, docs, QA, credentials and source maps; rejects traversal/symlink assets/output. Manifest records revision and asset hashes.
- `api/_lib/request-security.js`: exact HTTPS origins, POST-only, bounded body, injected authentication and shared limiter, private no-store, generic errors, fail closed on unavailable controls. Origin is never authentication; no-Origin requests still require authentication. No in-memory limiter masquerades as global quota. The guard is not live enforcement.
- `deployment/vercel-protected.template.json`: inactive candidate; must be reviewed against a real Vercel build. All Deployments protection is a dashboard/project setting, not supplied by this JSON. Never replace active vercel.json without approved target verification.
- Security CI: read-only contents permission, no persisted checkout credential, full history scan, dependency audit, regressions and packaging. It does not publish.
- Existing gateway credentials remain server environment variables. Avoid tokens in query strings/logs. Provider redirects rejected.

## Tester access and feedback

Recommend individually invited Vercel external collaborators for identifiable, individually revocable access. They need no GitHub account or repository permission, but protected viewing/comments require a Vercel account. Sending invitations requires founder approval. No invitations created.

Alternative: revocable shareable bypass link for a small trusted group; no repository account. Anyone holding/forwarding the link can view and download browser assets, so it is weaker than identity access. Do not promise per-person revocation for a group link; revoke the link and reissue only to approved people. Hobby permits only one shareable link in total per account.
